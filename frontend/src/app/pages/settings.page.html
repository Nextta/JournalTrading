integration_instructionsCómo conectar tus plataformas

MetaTrader 5

  1. Compila TradingJournalBridge.mq5 en MetaEditor y adjúntalo a un gráfico.
  2. En las propiedades del EA, configura el endpoint {{ endpoint() }} y la API key.
  3. Activa el trading algorítmico y deja el terminal abierto.
  4. El EA enviará un heartbeat cada 5 segundos y sincronizará el historial automáticamente.

NinjaTrader 8

  1. Cierra NinjaTrader y ejecuta tools\install-nt8-bridge.ps1. También puedes copiar nt8\JournalTradingBridge.cs a Documents\NinjaTrader 8\bin\Custom\AddOns y compilar con el editor de NinjaScript.
  2. Pulsa Escribir configuración NT8 para generar JournalTradingBridge.json con la API key y el puerto actuales.
  3. Abre NinjaTrader 8. El AddOn se carga automáticamente y envía un heartbeat cada 5 segundos.
  4. La primera vez, la cuenta aparecerá pendiente en Cuentas. Actívala para empezar a guardar su historial y diario.

El AddOn recupera las ejecuciones históricas de la base de datos local de NinjaTrader y solicita las velas bajo demanda al abrir un gráfico. No envía órdenes.
