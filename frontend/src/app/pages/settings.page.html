integration_instructionsCómo conectar tus plataformas

MetaTrader 5

  1. En MT5, ve a Herramientas > Opciones > Asesores expertos, activa Permitir WebRequest para las siguientes URL y añade {{ apiOrigin() }}. Sin esto, el EA no puede comunicarse con la app.
  2. Compila TradingJournalBridge.mq5 en MetaEditor y adjúntalo a un gráfico.
  3. En las propiedades del EA, configura el endpoint {{ endpoint() }} y la API key.
  4. Activa el trading algorítmico y deja el terminal abierto.
  5. El EA enviará un heartbeat cada 5 segundos y sincronizará el historial automáticamente.

NinjaTrader 8

  1. Cierra NinjaTrader y pulsa Instalar AddOn NT8 en la tarjeta de NinjaTrader de arriba. Copia el AddOn, lo compila (necesita Visual Studio Build Tools) y escribe la configuración con la API key y el puerto actuales. Sin Build Tools, copia nt8\JournalTradingBridge.cs a Documents\NinjaTrader 8\bin\Custom\AddOns y compila con F5 en el editor de NinjaScript.
  2. Si más adelante cambias el puerto o la API key, pulsa Escribir configuración NT8 para actualizar JournalTradingBridge.json.
  3. Abre NinjaTrader 8. El AddOn se carga automáticamente y envía un heartbeat cada 5 segundos.
  4. La primera vez, la cuenta aparecerá pendiente en Cuentas. Actívala para empezar a guardar su historial y diario.

El AddOn recupera las ejecuciones históricas de la base de datos local de NinjaTrader y solicita las velas bajo demanda al abrir un gráfico. No envía órdenes.

ATAS X

El historial se importa solo: la app lee la base de datos local de ATAS (%APPDATA%\ATAS X\Database) aunque ATAS esté cerrado y la relee cada 5 segundos cuando cambia. El indicador es opcional y añade tiempo real y velas para los gráficos.

  1. Comprueba en la tarjeta ATAS X de arriba que se haya detectado la base de datos. Las cuentas aparecerán pendientes en Cuentas; actívalas para empezar a guardar su historial y diario.
  2. Opcional, para tiempo real, velas y copy trading: cierra ATAS y pulsa Instalar AddOn ATAS en la tarjeta de ATAS X de arriba. Compila el indicador con el SDK de .NET 10, copia JournalTradingBridge.dll a %APPDATA%\ATAS X\Indicators y escribe la configuración.
  3. Abre ATAS y añade el indicador JournalTrading Bridge (categoría JournalTrading) a un gráfico de la cuenta que quieras seguir. Basta un gráfico por cuenta.

Se ignoran las cuentas Replay, Backtest y Playback, y las que ATAS recibe desde NinjaTrader 8 (ya las sincroniza el AddOn de NT8). Sin el indicador, las operaciones de ATAS no tienen velas en los gráficos. Si el indicador no conecta, revisa el registro de ATAS: los errores aparecen con el prefijo JournalTrading:.

Copy trading

Usa los mismos bridges: el rol de cada cuenta (principal o secundaria) se asigna en la página Copy trading. Los futuros se copian entre MT5, NinjaTrader 8 y ATAS; los CFD y el Forex, solo entre cuentas de MT5.

  1. Actualiza los bridges a la última versión: el EA de MT5 (1.2.0) y, con los botones Instalar AddOn NT8 e Instalar AddOn ATAS de arriba, el AddOn de NinjaTrader y el indicador de ATAS.
  2. MT5: deja el EA abierto en cada terminal, con el botón Algo Trading activo. En las secundarias, activa también Permitir trading algorítmico en las propiedades del EA.
  3. NinjaTrader 8: el AddOn atiende todas las cuentas conectadas. No hace falta nada más.
  4. ATAS: ATAS solo deja operar la cuenta y el instrumento de cada gráfico. En cada cuenta secundaria abre un gráfico por instrumento que quieras copiar y añade el indicador JournalTrading Bridge.
  5. En Copy trading, crea un grupo, elige la cuenta principal, añade las secundarias y configura su gestión. Después activa el grupo y el interruptor Copia activa.

Lo que ya estaba abierto al activar la copia no se copia, y las operaciones manuales de las secundarias no se tocan. Prueba primero con cuentas demo o de simulación.
